🔊 Écouter les mots

La voix utilise les voix installées dans le navigateur. Choisis une langue puis écoute un exemple.

La disponibilité des voix dépend de l'appareil et de sa connexion.

🔄 Transférer la progression entre tablette et ordinateur

Cette première version enregistre les progrès sur chaque appareil. Pour les retrouver sur un autre appareil, exporte la sauvegarde ici puis importe le fichier sur l'autre appareil.

La synchronisation automatique par Internet nécessitera une prochaine étape avec un espace cloud sécurisé. Aucun compte ni abonnement n'est requis pour cette version.

📱 Installer l'application

Sur Android : ouvre cette application dans Chrome, menu ⋮, puis « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Sur ordinateur : utilise le bouton « Installer » dans la barre du haut ou l'icône d'installation du navigateur.

🧹 Réinitialiser la progression

Cette action efface les étoiles et les missions terminées sur cet appareil.
